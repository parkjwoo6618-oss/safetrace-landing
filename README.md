# SAFETRACE Landing Page

개인정보 유출 감시 앱(가상 브랜드) 랜딩 페이지입니다.

- `index.html` 단일 파일 완결형 (외부 라이브러리/이미지 없음)
- 다크 테마, 스크롤 리빌, 카운트업 통계, 방문자 브라우저 지문 스캔 데모
- GitHub Pages 로 바로 호스팅 가능

## 배포

Settings → Pages → Source: `main` / `/ (root)` 선택 후 저장하면
`https://parkjwoo6618-oss.github.io/safetrace-landing/` 에서 공개됩니다.
